
# 🤖 AI Maze Solver

An interactive maze-solving visualization that demonstrates Breadth-First Search (BFS), a fundamental AI search algorithm.

## Features

- Randomly generated maze walls
- Animated AI search process
- Shortest path visualization
- Visited-cell and path-step counters
- New Maze and Reset controls
- Responsive design
- No external libraries or API keys

## Technologies

- HTML5
- CSS3
- JavaScript
- Breadth-First Search (BFS)

## How to Run

Open `index.html` in a web browser, or deploy the project using GitHub Pages.

## GitHub Pages Setup

1. Open the repository's Settings.
2. Select Pages.
3. Choose Deploy from a branch.
4. Select `main` and `/ (root)`.
5. Save and open the published link.

## How It Works

BFS explores the maze one level at a time. It records each cell's predecessor and reconstructs a shortest path from the start to the goal. The displayed path is shortest in terms of the number of grid moves.

## Files

- `index.html` — page structure
- `style.css` — visual styling
- `script.js` — maze generation and BFS algorithm
- `README.md` — documentation

## Educational Purpose

This project demonstrates graph traversal and shortest-path search. It is a visualization of an AI algorithm, not a trained machine-learning model.
